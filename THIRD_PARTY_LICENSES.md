# Componentes de terceiros e licencas

Este documento e um indice. Para redistribuicao, preserve tambem os cabecalhos de copyright dentro dos arquivos-fonte.

## x2600 / Virtual 2600

Arquivos do nucleo contêm avisos do x2600/Virtual 2600 declarando distribuicao sob a **GNU General Public License** e remetendo ao arquivo COPYING original. O site historico do autor confirma a distribuicao sob GNU GPL.

Como o pacote adaptado nao veio acompanhado do COPYING historico exato, este repositorio evita afirmar uma versao especifica da GPL para todo o nucleo. Um texto de referencia GPL-2.0 e GPL-3.0 esta incluido apenas para consulta; os cabecalhos originais continuam sendo a fonte primaria para cada arquivo.

## TiaSound

`Tiasound.c` declara explicitamente **GNU Library General Public License version 2**. Copia de referencia em `licenses/LGPL-2.0.txt`.

## DabbleESP32

Upstream: https://github.com/STEMpedia/DabbleESP32

Licenca declarada pelo repositorio: **GNU Lesser General Public License v3.0**.

Copia de referencia em `licenses/LGPL-3.0.txt`.

## TFT_eSPI

Upstream: https://github.com/Bodmer/TFT_eSPI

O `license.txt` upstream documenta multiplas origens/licencas: Adafruit_ILI9341 (MIT), funcoes Adafruit_GFX (BSD) e codigo original de Bodmer sob FreeBSD. Veja `licenses/TFT_eSPI-license-summary.txt` e consulte sempre o arquivo original upstream para a versao atual.

## ESP32 Arduino Core / LittleFS / WiFi / HTTPClient

Fornecidos pelo pacote Arduino-ESP32/Espressif instalado no ambiente Arduino. Eles nao sao copiados para este repositorio; aplicam-se os termos dos respectivos pacotes upstream.

## ROMs e catalogos

ROMs nao sao licenciadas pelo HALO 2600 RETRO. Consulte `docs/ROMS_AND_LEGAL.md`. Em especial, Retrobrews afirma que as ROMs de sua colecao foram autorizadas para distribuicao gratuita naquele site/projeto apenas.
