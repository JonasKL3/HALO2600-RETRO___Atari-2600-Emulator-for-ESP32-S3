# DabbleESP32

- Projeto: STEMpedia/DabbleESP32
- https://github.com/STEMpedia/DabbleESP32
- Uso aqui: GamePad Bluetooth
- Licenca upstream: LGPL-3.0

A biblioteca e instalada separadamente pelo usuario; nao foi vendorizada dentro do firmware.

**Nota de estabilidade:** a biblioteca pode apresentar `heap_caps_free` com pacotes BLE incompletos; consultar `docs/DABBLE_BLE_RESET.md` e `tools/CORRIGIR-DABBLE-ESP32S3.ps1` antes da recompilacao. Falha confirmada no SPACE SHOOTER, nao no HALO.
